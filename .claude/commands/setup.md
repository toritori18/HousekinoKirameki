初回セットアップを行います。使用するスタック（言語・フレームワークの組み合わせ）を選んで、その設定をリポジトリに展開します。

まず、引数でスタック名が指定されているか確認してください。

指定が無い場合は、以下を実行して利用できるスタックの一覧を表示し、どれを使うかユーザーに確認してください。この呼び出しでは何も変更されません。

```powershell
.\.claude\commands\setup.ps1
```

スタックが決まったら、スタック名を渡して実行してください。

```powershell
.\.claude\commands\setup.ps1 -Stack $ARGUMENTS
```

このスクリプトは以下を行います。

1. `stacks/<スタック名>/files/` の内容をリポジトリルートへ展開する（既存ファイルは上書きせずスキップする）
2. `stacks/<スタック名>/stack.json` を `.claude/project.json` として配置する
3. `.env.example` から `.env.local` を作成する
4. `.claude/project.json` の `install` に定義されたコマンドで依存パッケージをインストールする

既存ファイルを上書きしたい場合のみ `-Force` を付けます。破壊的な操作なので、付ける前に必ずユーザーの同意を得てください。

git の初期化と hooks（push 前の機密情報チェック）の登録はこのスクリプトには含まれません。別コマンド /git:init で行ってください。

セットアップ完了後、以下を案内してください。

1. `.env.local` に必要な接続情報を設定すること
2. /git:init で git リポジトリの初期化と hooks の登録を行うこと
3. README.md と docs/tech-stack.md のプレースホルダ（波かっこ2つで囲まれた箇所）を埋めること
