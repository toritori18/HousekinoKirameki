コミットメッセージを引数として受け取り、コミット＆プッシュを行います。

まず、未追跡の新規ファイルがないか確認してください。

```powershell
git status --porcelain
```

`??`（未追跡）のファイルがある場合は、その一覧をユーザーに提示し、コミットに含めるべきファイルだけを `git add <ファイル>` でステージングしてください。ログ・一時ファイルなど含めるべきでないファイルは追加せず、必要に応じて `.gitignore` への追加を提案してください。

その上で、以下のスクリプトを実行してください（追跡済みファイルの自動ステージング → シークレットチェック → コミット → プッシュ）。

```powershell
.\.claude\commands\git\push.ps1 "$ARGUMENTS"
```

引数が指定されていない場合は、変更内容をもとに適切なコミットメッセージを提案してから実行してください。
