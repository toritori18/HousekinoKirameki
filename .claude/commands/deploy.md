本番環境へのデプロイを行います。

## 自動デプロイ（推奨）

`main` への直接プッシュは禁止です（[docs/git-rules.md](../../docs/git-rules.md)）。**PR 経由で main にマージ**すると、ホスティングサービスが自動的にデプロイします。

1. デプロイ前チェックリスト（下記）を確認する
2. 作業ブランチの変更をコミット・プッシュする: /git:push "feat: 変更内容"
3. PR を作成する: /git:pr
4. CI の成功を確認して main へマージする: /git:merge → ホスティングサービスが自動デプロイ

## デプロイ前チェックリスト

デプロイ前に以下を確認してください:

1. /check が通ること（ドキュメントの参照先検査・静的解析・型検査・テスト・本番ビルドの一括実行）
2. `.env.local` の環境変数が、ホスティングサービスのプロジェクト設定にも**本番向けとして**登録されていること
3. 環境変数を追加・変更した場合は、保存したうえで再デプロイすること（多くのホスティングサービスでは、デプロイを作成した時点の環境変数が固定されます）

## 手動デプロイ

手動デプロイの手順は、使用しているホスティングサービスによって異なります。
**このプロジェクトの手順は [docs/tech-stack.md](../../docs/tech-stack.md) の「インフラ / ホスティング」に記載してください。**

記載が無い場合は、推測でコマンドを実行せず、ユーザーにデプロイ先と手順を確認してください。
