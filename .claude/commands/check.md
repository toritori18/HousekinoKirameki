プッシュ前の総点検として、以下のコマンドを実行してください。

```powershell
.\.claude\commands\check.ps1
```

`.claude/project.json` の `check` に並んでいるステップを上から順に実行し、途中で失敗したら後続を実行せず停止します（`exit 1`）。

- `verify-docs` — ドキュメントの参照先検査（`verify-docs.ps1`）。`.md` の相対リンクのリンク先・アンカー（`#見出し`）・言及されているスラッシュコマンド（コマンド・スキル・組み込みコマンド）が実在するかを確認します
- それ以外のステップ — `.claude/project.json` の `commands.<ステップ名>` に定義されたコマンドを実行します

コマンドが未設定のステップはスキップされ、最後にスキップした項目がまとめて表示されます。
`.claude/project.json` がまだ無い場合（/setup 前）は、ドキュメントの参照先検査のみ実行します。
