データベースのスキーマ変更（マイグレーション）を行います。

このプロジェクトのマイグレーション方式は [docs/tech-stack.md](../../../docs/tech-stack.md) の「データベース・認証」に記載してください。記載が無い場合は、推測で実行せずユーザーに方式を確認してください。

## SQL ファイルを手動で適用する運用の場合

1. `docs/sql/` に新しいマイグレーション用 SQL ファイルを追加する（既存ファイルは変更せず、新規ファイルとして追加する）
2. データベースの管理画面（SQL Editor 等）で内容を確認しながら実行する
3. テーブル・カラムが意図どおり作成されたことを確認する
4. スキーマ変更が型定義・モデルクラスに影響する場合は、あわせて更新する

> `docs/sql/` は `.gitignore` でフォルダ自体のみ追跡する設定です（[.gitignore](../../../.gitignore) 参照）。版管理したい SQL がある場合は、除外設定を見直してからコミットしてください。

## マイグレーションツールを使う運用の場合

プロジェクトで採用しているツールのコマンドを使用してください。ツール名とコマンドが [docs/tech-stack.md](../../../docs/tech-stack.md) に書かれていない場合は、実行前にユーザーへ確認してください。

## 注意事項

- 本番環境で実行する前に、必ずローカルまたはステージング環境で動作確認する
- 破壊的な変更（列削除・型変更等）を行う前に、既存データのバックアップを取得する
- 接続情報・シークレットはコマンドや SQL ファイルに直書きせず、`.env.local` 経由で参照する
