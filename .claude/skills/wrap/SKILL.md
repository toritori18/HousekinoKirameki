# 引き継ぎメモの書き出し（wrap）

**重要: 書くのは「目的」「未完了と次の一手」「決定事項と理由」の3項目だけ。会話で実際に出た事実だけを書き、推測で埋めない。短く保つ。**

## 手順

1. このセッションですでに読み込んだ、または書いたメモがあれば、そのファイルを更新する。無ければ新規作成する
2. 新規作成のファイル名は、作業内容を表す英小文字ケバブケースにする（例: `.claude/handoff/login-form.md`）。同名があれば別の名前にする（既存のメモを上書きしない）
3. 下記の書式で書く
4. 引数（`$ARGUMENTS`）が `done` のとき: メモの内容を最後の状態に更新したうえで、`.claude/handoff/archive/` へ移動する（完了扱い。ディレクトリが無ければ作る）
5. 書き終えたら、ユーザーに「/clear で区切れます」と1行伝える（`/clear` はユーザーが手で打つ。Claude からは実行できない）

## 書式

SessionStart フックの一覧表示が先頭3行を読むため、この書式は変えないこと。

```
# <作業名（日本語可）>
次の一手: <1行>
更新: YYYY-MM-DD

## 目的
（何のための作業か。1〜3行）

## 未完了と次の一手
（終わっていないことと、次に着手すること。箇条書き）

## 決定事項と理由
（決めたことと、その理由。箇条書き）
```

- `更新:` の日付は今日の日付（`Get-Date -Format "yyyy-MM-dd"` で取得する）
- 「次の一手」は、次のセッションの最初に何をするかが1行で分かるように書く
- 項目が無い節は「なし」と書く
- コードや会話の全文は貼らない。ファイル名・関数名・判断だけを書く

## 注意事項

- メモは `.gitignore` 対象（git で管理しない）
- 全体の流れと jev が無い場合の動作は [docs/handoff.md](../../../docs/handoff.md) を参照
