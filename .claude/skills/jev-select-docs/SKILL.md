# 作業前の資料選び（jev）

## いつ使うか

作業に着手する前に、**読む資料を絞りたいとき**に使う。`docs/` の資料が増えると全部は読めず、かといって読み漏らすと規約違反や手戻りにつながる。jev に作業内容と各資料の冒頭を見せ、作業との関係の深さを採点させる。

使わなくてよい場面: 読むべき資料が既に分かっているとき、資料が数件しかないとき。

## 実行方法

作業内容を自然文で渡す。

```powershell
.\.claude\jev\select-docs.ps1 -Task "ログイン画面にパスワード再設定リンクを追加する"
```

- 候補は `docs/` 配下の `.md`（再帰）と `README.md`。`.claude/project.json` の `docsExclude` に一致するものは除く
- 候補が多い場合は先頭から 40 件までを対象にし、その旨が表示される
- 各資料の「パス・最初の見出し・冒頭の本文（400 文字程度）」だけを jev に送る。資料の全文は送らない

## 出力の読み方

1行につき1資料で、`パス` と `スコア` がタブ区切りで並ぶ（スコアの高い順、既定は上位 3 件）。

| スコア | 意味 |
|---|---|
| 3 付近 | 読むと作業の進め方が変わる（守るべき規約・手順・制約が書かれている） |
| 2 付近 | 作業の参考になる |
| 1 付近 | 同じ分野の資料。読まなくても作業はできる |
| 0 付近 | 無関係（既定では出力されない） |

スコアは目安であり、判断の補助にすぎない。出力された資料は作業前に読む。出力に無い資料が読むべきでないとは限らないため、作業内容に明らかに関係する規約ドキュメントは別途読むこと。

## スキップされたとき

次のいずれかで「jev をスキップしました。資料は自分で選んでください」と表示され、終了コード 0 で終わる。

- API キー（`TYPESAFE_API_KEY`）が無い
- モードが off（環境変数 `JEV_MODE_SELECTDOCS` または `JEV_MODE`、`.claude/jev/config.json` で指定）
- 通信の失敗やタイムアウト

この場合は従来どおり、`README.md` と `docs/` の目次から自分で資料を選ぶ。エラーではないので、作業を止めたり、ユーザーに報告したりする必要はない。

## 注意事項

- 設定（件数の上限・最低スコア）と呼び出しの記録は [docs/jev.md](../../../docs/jev.md) を参照
- 送信するのは資料の抜粋と作業内容のみ。機密情報を作業内容に書かないこと
